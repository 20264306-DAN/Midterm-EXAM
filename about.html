About me

My name is Dan Clyde, a ComSci student aspiring to master front-end web development principles. Below are my core focus areas:

  • Document Structure: Arranging the page into logical zones like headers, main content, and footers so browsers know exactly where everything belongs.
  • Text Hierarchy: Organizing text into a strict order of main titles, subtitles, and standard paragraphs so the page reads like a well-structured book.
  • Hyperlinks: Creating clickable text or image pathways that connect the user to different pages or external websites.
  • Forms and Inputs: Setting up text boxes, checkboxes, and buttons so users can type information and interact with the website.
  • Media Embedding: Placing images, videos, and audio onto the screen and providing text descriptions for them
